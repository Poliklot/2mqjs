Issue #3 / очистка worker-условия задачи

Очистка worker-условия задачи

Сценарий запускает задачу с условием worker:name, дожидается name:ready и затем повторно отправляет тот же ready-порт.

Как проверить вручную

  1. Откройте DevTools → Console.
  2. Нажмите «Проверить worker».
  3. После выполнения задачи повторный ready emit не должен печатать старый [tasks] when лог.

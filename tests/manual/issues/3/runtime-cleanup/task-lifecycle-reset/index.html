Issue #3 / сброс lifecycle задачи

Инвалидизация ожидания и retry

Сценарий проверяет поздний результат пользовательского function-when и ожидающий retry-delay после вызова resetTasks().

Как проверить вручную

  1. Откройте DevTools → Console.
  2. Нажмите «Проверить сброс lifecycle».
  3. Function-when не должен запустить задачу, а retry не должен выполнить вторую попытку.

09

runTasks → resetTasks → позднее завершение

Оба старых lifecycle должны завершиться без запуска нового пользовательского кода.

Issue #3 / очистка port задачи

Очистка port задачи

Сценарий запускает задачу с условием port:a, дожидается порта и затем повторно отправляет тот же порт.

Как проверить вручную

  1. Откройте DevTools → Console.
  2. Нажмите «Проверить port».
  3. После выполнения задачи повторный emit не должен печатать старый [tasks] when лог.

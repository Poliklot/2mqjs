Issue #3 / task data reset

Task data polling cleanup

Сценарий запускает задачу с условием data:__manualTaskDataReady, сразу вызывает resetTasks(), а потом создаёт эти данные.

Как проверить вручную

  1. Откройте DevTools → Console.
  2. Нажмите «Проверить data polling».
  3. После reset появление данных не должно запускать Task.run().

Issue #3 / очистка allPorts задачи

Очистка allPorts задачи

Сценарий запускает задачу с условием allPorts:a,b, дожидается обоих портов и затем повторно отправляет те же порты.

Как проверить вручную

  1. Откройте DevTools → Console.
  2. Нажмите «Проверить allPorts».
  3. После выполнения задачи повторные emit не должны печатать старые [tasks] when логи.

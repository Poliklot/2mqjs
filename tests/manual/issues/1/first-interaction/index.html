Issue #1 / Components

Первое взаимодействие

Реальный import() и обработка первого действия из boot-контекста.

Как проверить вручную

  1. Выберите режим: click, keyboard, pointer или touch.
  2. Нажмите «Повторить сканирование» несколько раз: load и boot должны оставаться равны 0.
  3. Нажмите «Добавить товар» (для keyboard — Enter, для touch — касание на touch-устройстве).
  4. После первого действия load, boot и действия равны 1; исходное событие сохранено.
  5. Перезагрузите страницу и нажмите checkbox: его нативное переключение не блокируется.
